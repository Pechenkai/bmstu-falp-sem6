# Лабораторные работы по функциональному и логическому программированию

Репозиторий содержит решения лабораторных работ по дисциплине «Функциональное и
логическое программирование». Основная часть заданий выполнена на Common Lisp;
в лабораторной работе №7 используется Visual Prolog 5.2.

## Состав репозитория

| Каталог | Содержание |
| --- | --- |
| `lab_04` | Базовые операции со списками и две реализации игры в кости. |
| `lab_05` | Обработка списков с помощью функций высшего порядка: `mapcar`, `reduce`, `every` и `mapcan`. |
| `lab_06` | Рекурсивные алгоритмы для плоских и вложенных списков. |
| `lab_07/docs` | Исходники отчёта в LaTeX и программы Visual Prolog «Телефонный справочник и автомобили». |

## Лабораторная работа №4

Задания `task1.lsp`–`task6.lsp` посвящены стандартным операциям над списками:
получению и удалению последнего элемента, перестановке первого и последнего
элементов, а также моделированию игры в кости. В `task5.lsp` и `task6.lsp`
представлены два варианта игры.

## Лабораторная работа №5

| Файл | Назначение |
| --- | --- |
| `task1.lsp` | Вычитание 10 из числовых элементов списка. |
| `task2.lsp` | Возведение элементов числового списка в квадрат. |
| `task3.lsp` | Умножение элементов списка на число, включая рекурсивный вариант для вложенных списков. |
| `task4.lsp` | Проверка списка на палиндром. |
| `task5.lsp` | Проверка равенства множеств. |
| `task6.lsp` | Отбор чисел из диапазона; второй вариант сортирует результат. |
| `task7.lsp` | Декартово произведение двух списков. |
| `task8.lsp` | Поведение `reduce` для пустого списка. |
| `task9.lsp` | Подсчёт общего числа элементов в списке списков. |
| `deff.lsp` | Вычисление значения двоичной записи. |

## Лабораторная работа №6

В заданиях `task1.lsp`–`task10.lsp` реализованы рекурсивные функции: обращение
списка, поиск первого подсписка и первого нечётного элемента, умножение и
суммирование элементов, выборка с сортировкой, получение элемента по индексу,
проверка нечётности, возведение в квадрат и разворачивание вложенного списка.

## Лабораторная работа №7

Программа Visual Prolog описывает телефонный справочник и автомобили владельцев.
Правило `find_owner_by_car` по марке и цвету автомобиля находит фамилию владельца,
город и номер телефона.
